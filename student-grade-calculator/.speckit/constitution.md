# Project Constitution

## Project Name
Student Grade Calculator API

## Overview
A RESTful API for managing student records, recording scores, calculating letter grades, and generating academic reports. Built as an educational workshop project to demonstrate Spec-Driven Development (SDD) using GitHub's open-source speckit.

## Technology Stack
- **Language:** Python 3.12+
- **Framework:** FastAPI
- **Database:** SQLite (via SQLAlchemy 2.x ORM)
- **Validation:** Pydantic 2.x
- **Testing:** pytest + httpx

## Purpose
This project serves as a hands-on example for faculty workshops, demonstrating how to go from a formal specification document to a fully implemented, tested API using modern Python tooling.

## Core Domain
- Student registration and management
- Score recording with automatic grade calculation
- Report card generation with GPA computation
- Class-level statistics and analytics
